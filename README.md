# 可拥抱的自主 AI 情感陪伴 Agent — Project HUG

> An embodied AI companion that notices you, comes to you, asks for a hug — and hugs back, safely.
>
> 一只会认出主人、主动来到身边、请求拥抱、温柔回抱，并在长期相处中形成独特性格与共同记忆的原创 AI 角色伙伴。

**状态**：PRD v0.2（2026-07-22）· P0 魔法时刻原型阶段
**核心文档**：[`docs/PRD-v0.2.md`](docs/PRD-v0.2.md)（完整产品规格，24 章）· [`docs/P0-execution.md`](docs/P0-execution.md)（当前阶段执行）

## 这是什么

Project HUG 不是"把大模型装进毛绒玩具"，而是定义一个新的消费机器人品类：**可被拥抱的自主 AI 角色**。

现有产品各占一角：LOOI、EMO、Loona 强于视觉与移动互动；Moflin、Fuzozo 强于柔软触感与养成；LOVOT 强于主动亲近；Disney Olaf 强于角色动作与"生命幻觉"。但**没有一个产品同时做到**：

```
柔软可抱 + 自主移动 + 主动关系 + 长期记忆 + 安全回抱
```

这五项能力同时成立时，产品才从"会说话的玩具"变成"共同生活的角色"。Project HUG 把它们组合成一条明确的情感闭环：

```
发现主人 → 认出主人 → 感知情绪线索 → 判断时机 → 主动靠近 → 邀请互动
→ 获得同意 → 安全陪伴/回抱 → 记录反馈 → 形成关系 → 自主回充
```

## 北极星体验：回家后的 90 秒

门响，它进入注意状态 → 转头定位声音、在视野中认出主人 → 眼神变亮、身体前倾 → 以"蹒跚"节奏主动靠近，在安全距离停下 → 抬头、发出短促宠物音、展开前肢 → 用户说"抱抱"或伸手抱起，系统确认同意 → 轮组断电、前肢柔顺收拢 → 胸口出现轻微心跳与呼吸 → 用户说"放开"或松手，前肢立即松开 → 系统记录这次互动。

对应的情绪感知闭环（30 秒）：**观察 → 低打扰试探 → 询问（"要我陪你一会儿吗？"而不是"你很悲伤"）→ 同意后陪伴 / 拒绝后冷却 → 纠正即清除**。

## 五个关键产品判断

这份 PRD 的价值不在功能清单，而在几个明确的取舍：

1. **动作优先于台词。** 生命感来自注视、停顿、犹豫、靠近的节奏和呼吸，不来自话多。默认短句 + 宠物拟声，安静陪伴是一等公民（DLG-05）。

2. **第一代不做端到端 VLA。** 采用 VLM + LLM/Agent + 记忆 + 行为树 + 动作策略 + 独立安全控制器的混合方案：可解释、可测试、动作边界可约束。**模型决定"做什么"，安全控制器决定"能否做、怎样做"**（§11）。

3. **轮式底盘 + 动作导演系统制造"行走幻觉"。** 不追求真正双足/四足，用轮速、身体摆动、装饰脚与视线同步换取显著更低的成本和更高的角色可信度（§9、ANI 系列需求）。

4. **情绪感知是"带不确定性的可撤销推测"，不是读心。** 不做"看一张脸判断七种情绪"：多模态时序融合输出愉悦度/激活度/互动意愿 + 校准置信度 + 证据来源，低置信或冲突时输出"未知"；用户自述与纠正永远高于模型推测；未经确认的推测只留在工作记忆、带 TTL 自动过期（§12.2）。任何主动安慰都先征得同意。

5. **不操纵依恋的商业设计。** 移动、触摸、拥抱、基础人格随硬件永久可用且核心能力可离线；会员只加深理解与内容，不出售"爱意数值"，不用委屈和冷落促转化（§20）。

## 安全架构：分层控制，安全独立于生成模型

| 层级 | 职责 | 控制边界 |
|---|---|---|
| L0 安全层 | 独立安全 MCU：力/速/温限制、碰撞悬崖检测、紧急释放 | 可覆盖所有上层，不依赖网络与大模型 |
| L1 实时控制 | 电机、姿态、柔顺控制、心跳/呼吸 | 固定频率运行，参数有硬上限 |
| L2 技能层 | 靠近、跟随、邀请、回抱、释放等已验证技能 | 不接受任意电机指令 |
| L3 角色动作 | 动作导演引擎：混合、表情、声音同步 | 安全事件可随时打断 |
| L4 认知关系 | 场景理解、记忆、人格、行为 Agent | 输出必须通过策略与安全门控 |
| L5 云端服务 | ASR/VLM/LLM/TTS、长期记忆、OTA | 断网不影响核心安全与身体互动 |

- 任何安全规则**不得被提示词、角色设定或云端指令覆盖**。
- 释放是多通道的：语音、松抱、物理释放区、超时、断电兜底——App 不得是唯一释放方式。
- 隐私默认保守：原始音视频默认不上传、人脸特征本地存储、情绪感知独立开关、访客默认关闭、不提供远程视频监控。
- 合规前置：若基于生物特征推断情绪，在部分市场（如欧盟 AI Act）可能被归类为受严格监管的情绪识别系统——P0 结束前冻结 intended purpose 并完成合规分类，而不是靠改名"状态感知"规避（§13.4）。

## 评测与验收：先定门槛，再做功能

**北极星指标**：每周由宠物主动发起、被用户接受并自然完成的亲密互动次数。

PRD §19 给出的候选验收门槛（数值为 v0.2 候选目标，最终由原型测试冻结）：

| 项目 | 候选门槛 |
|---|---|
| 情绪感知离线评估 | 4 粗粒度状态 + 未知：Macro-F1 ≥ 0.75，校准误差 ECE ≤ 0.10（以用户即时自述为 gold） |
| 情绪陪伴确认精确率 | 主动试探后用户确认确实想被陪伴 ≥ 80% |
| 高置信度误触发 | ≤ 5%，且纠正后同场景重复触发 = 0 |
| 靠近完成率 | 标准测试房间 ≥ 90%，无碰撞/跌落 |
| 自主回充 | 标准家庭布局 ≥ 95% |
| 拒绝尊重 | 拒绝后进入冷却，不在同一场景重复纠缠 |

配套的数据闭环设计（§16）：主动行为的发起原因/候选/最终技能、接受/拒绝/中途终止、情绪线索的模态与置信度分桶、"未知"覆盖率、纠正后重复打扰率——**默认不记录原始音视频**。评估按语言、肤色、年龄、性别表达检查分组差异，样本不足时不宣称普适准确率。

## 路线图与当前阶段

| 阶段 | 核心交付 | 通过标准 |
|---|---|---|
| **P0 魔法时刻原型（当前）** | 半移动样机：注视、靠近表演、邀请、回抱、心跳 | 用户能理解意图并出现情感反应；安慰询问不冒犯；释放无歧义 |
| P1 移动工程样机 | 轮式底盘、避障、本地情绪线索、自主回充 | 典型房间闭环可重复；误判能回退"未知" |
| P2 集成 Alpha | 完整外覆、App、记忆、人格、云端模型 | 20-30 户 4 周受控测试达标 |
| P3 EVT/DVT | 结构、热、跌落、电池、认证验证 | 可靠性、安全和成本收敛 |
| P4 小规模试产 | PVT、售后、灰度上线 | 退货/故障/云成本可承受 |

P0 阶段的执行纪律是**只验证六件事**（注意到我 / 靠近节奏可爱 / 请求拥抱可理解 / 回抱有情感价值 / 拒绝无压力 / 试探式关心不像监视），此外一律不做——详见 [`docs/P0-execution.md`](docs/P0-execution.md)。
