# Project HUG — 可拥抱的 AI 情感陪伴 Agent

> 立项日期：2026-07-22。产品规格以 `docs/PRD-v0.2.md`（原件 `docs/可拥抱自主AI角色宠物_PRD_v0.2.docx`）为准，本 README 只管**当前阶段的执行**。
>
> 产品一句话：一只会认出主人、主动来到身边、请求拥抱、温柔回抱，并在长期相处中形成独特性格与共同记忆的原创 AI 角色伙伴。

- **本仓 = 产品层**：PRD、角色圣经、评测体系、用户研究。
- **`~/companion-doll` = P0 原型载体**：BOM、接线、里程碑 1-3（会说话/有反射/会过来）已就绪，元件采购中。P0 新增硬件缺口见下。
- 当前阶段：**P0 魔法时刻原型**（PRD §18 定义为 0-8 周）。

## P0 只验证六件事（PRD §18.1，执行纪律：此外一律不做）

1. 它能用视线和身体姿态让用户感到"它注意到我了"
2. 它靠近的节奏是可爱而非机械或吓人
3. 用户能自然理解"它在请求拥抱"
4. 被抱起后的回抱、心跳和呼吸能产生情感价值
5. 用户能毫无压力地拒绝和结束互动
6. 它以"不确定、先询问"的方式回应情绪线索时，用户感到被关心而非被监视

## 里程碑 4（P0 完成线，接在 companion-doll 里程碑 3 之后）

**拥抱闭环**：张开前肢 + 抬头 + 短音邀请 → 同意判定（语音"抱抱" / 伸手 / IMU 检测被抱起，满足其一）→ 底盘断电 + 前肢柔顺收拢（FSR 压力超阈即停）→ 心跳 + 呼吸起动 → 多通道释放（语音 / 松抱 / 超时 / 断电兜底）→ 记录接受/拒绝与持续时长。
📹 素材：全项目的北极星镜头（PRD §6.1"回家后的 90 秒"的桌面版）。

## 评测衔接（作品护城河所在）

companion-doll 作品件③（情绪识别校准报告）直接升级为 PRD §19 验收门槛的**预演**：

| PRD 候选门槛 | 值 | 备注 |
|---|---|---|
| 情绪感知离线评估 | 4 状态 + 未知 Macro-F1 ≥ 0.75，ECE ≤ 0.10 | gold 必须本人标注（German eval 项目同款纪律） |
| 情绪陪伴确认精确率 | ≥ 80% | 主动试探后用户确认确实想被陪伴的比例 |
| 高置信度误触发 | ≤ 5%，纠正后同场景重复 = 0 | |

单人阶段以"7 天使用日记 + 即时自述为 gold"替代 20-30 户 Alpha（PRD §16.4 已列此方法）。
