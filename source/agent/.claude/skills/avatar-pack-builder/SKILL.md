# 宠物资源包

1. 只处理用户本次明确上传的 JPEG、PNG 或 WebP，默认上限 8 MB。
2. 一次生成身份层，后续眼睛、嘴形与动画由确定性覆盖层合成。
3. 输出九种表情，每种五帧，并生成含尺寸、版本和 SHA-256 的 manifest。
4. 验证、生成、预览与激活分开；只有全部校验通过才原子激活。
5. 任一步失败保留 `basic` 或上一有效包；不记录或提交原图。
6. 可在当前 Session 工作区使用 Read/Write/Edit/Bash 检查临时资源。
